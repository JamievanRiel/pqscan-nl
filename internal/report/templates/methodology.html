Methodology

Every Monday a scanner performs TLS handshakes with Dutch websites and records which key exchange each server chooses. It does not request any web pages.

What is measured

For each domain the scanner connects to port 443 of the domain itself. If that does not complete a TLS handshake, it tries the www. host instead. It then runs up to two handshakes:

  1. Default handshake. The scanner offers what current browsers offer: the hybrid post-quantum group X25519MLKEM768 and the classic groups X25519, P-256 and P-384, over TLS 1.2 or 1.3. It records the group the server picks.
  2. Support check. Only when the server picked a classic group: a second handshake over TLS 1.3 that offers only the three hybrid post-quantum groups X25519MLKEM768, SecP256r1MLKEM768 and SecP384r1MLKEM1024. If it succeeds, the server supports post-quantum key exchange, but a current browser does not get it.

Statuses

StatusMeaning
Post-quantum by defaultThe default handshake used a hybrid post-quantum group. Traffic recorded today cannot be decrypted later with a quantum computer by breaking the key exchange.
Supported, not defaultThe server chose a classic group in the default handshake but completed the post-quantum-only handshake.
Classic onlyThe server used a classic group and refused the post-quantum-only handshake.
Not reachableNo TLS handshake completed on either host. These domains are left out of every percentage.

Which domains

The main figure covers every .nl domain in the Tranco top 1 million, a ranking of popular domains built for research. Each scan records the Tranco list ID, so its input can be reproduced.

The sector comparison uses curated lists, with a source for every entry:

  • Government: ministries, provinces, municipalities, water boards, agencies, independent administrative bodies, inspectorates, High Councils of State, the judiciary and the police, taken from the Organisaties overheid register, plus a few national services that the register lists as part of a ministry, such as the Belastingdienst.
  • Banks, hospitals and web shops: compiled from public lists.

The lists, with the source of every entry, can be downloaded as CSV: government, banks, hospitals and web shops. A domain can be in the Tranco list and in a sector list at the same time.

Hosting networks

Each server's IP address is mapped to its network (autonomous system) with the public-domain iptoasn.com table.

Limitations

  • Only port 443 of the domain and its www. host is checked. Redirects to other hosts are not followed, and mail servers are not measured.
  • Scans run from a GitHub Actions server in the United States. Sites behind a content delivery network may answer differently elsewhere.
  • The scanner is written in Go. Its handshake resembles a browser's but is not identical, so a few servers may choose differently for a real browser.
  • Servers that only speak TLS 1.1 or older, or only legacy cipher suites or signatures that Go refuses, and servers that stall on the large post-quantum ClientHello, show up as not reachable rather than classic only. Because unreachable domains are left out of the percentages, this slightly raises the headline figure.
  • Only key exchange is measured, not certificates or signatures.
  • Certificate validity is recorded in the raw data but does not change a domain's status.

Opting out

To exclude a domain from future scans, open an opt-out request on GitHub. The domain will be added to the exclusion list.

Data

The raw results of the latest scan hold one JSON record per domain, gzipped. The search page shows the status of a single domain.
